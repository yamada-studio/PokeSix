# 0003. 최소 Qt 6.8, aqtinstall 권장

- 상태: Accepted
- 날짜: 2026-09-28

## 맥락

배포 방식은 "clone → build → run"이고, 빌드 재현성이 확실해야 한다. 대상 OS는 Windows, Ubuntu 24.04, macOS다.
그런데 Ubuntu 24.04의 apt Qt는 6.4.2이고, Homebrew는 항상 최신(6.9 이상)이다.
Qt 6.8은 LTS이며, 오픈소스로 받을 수 있는 마지막 패치는 6.8.3이다.

## 선택지

1. **6.8 필수** — 세 OS가 같은 LTS로 빌드된다. Ubuntu에서는 apt를 쓸 수 없다
2. **6.4 최소, 6.8 권장** — apt로도 빌드된다. 대신 6.5 이후 API를 쓸 수 없고 테스트할 버전이 두 개가 된다

설치 방법: 온라인 인스톨러(계정 필요, GUI), Homebrew(버전 고정 불가), aqtinstall(계정 불필요, 스크립트화 가능, CI와 같은 방식).

## 결정

**`find_package(Qt6 6.8 REQUIRED)`**, 권장 설치 방법은 **aqtinstall로 6.8.3 고정**(`scripts/<os>/setup`, 버전은 `scripts/QT_VERSION`).
경로는 환경 변수 `QT_ROOT_DIR`로 받는다. aqtinstall과 GitHub Actions `install-qt-action`이 쓰는 이름과 같다.

## 결과

- 잘못된 Qt가 잡히면 configure 단계에서 버전 메시지와 함께 바로 실패한다
- Ubuntu에서는 `libxcb-cursor0` 등 일부 시스템 패키지를 따로 설치해야 한다(docs/build.md)
- 다시 검토할 조건: 다음 LTS가 나오고, 거기서만 쓸 수 있는 기능이 필요해질 때
