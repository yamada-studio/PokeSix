# 0010. 인트로 화면을 Claude가 구현하고, 그 과정의 기술 결정을 확정한다

- 상태: Accepted
- 날짜: 2026-09-29

## 맥락

A2(레이아웃)의 체크포인트 B2까지 진행한 뒤, 사용자가 명시적으로 요청했다.
"홈페이지 화면까지 전부 구현해 달라. OS별 아이콘과 디자인 스타일시트까지 입혀서. 설명과 주석도 남겨 달라."
CLAUDE.md의 가이더 역할은 사용자가 명시적으로 요청하면 구현을 허용한다. 그래서 Claude가 로드맵 A2의 나머지와 A4–A7 일부를 한 번에 구현했다.
구현하면서 로드맵의 열린 질문 두 개(5, 6)에 답이 필요했다.

## 결정

**구현 범위**
- 인트로(HomePage) 전체 모양: 바탕 무늬와 띠, 캡슐 마크, 워드마크, 부제, 세대 버튼(모양만), 메뉴 창, 메뉴 5줄, 정보 줄. 기준은 `30_intro_1440.png`
- 메뉴 동작: hover가 선택을 옮김, ↑↓(순환 없음), Enter, 1–4, Esc 두 번 = 종료, 눌림 모양
- 디자인 스타일: v2 토큰(`ui/theme/tokens.h`), 번들 글꼴 등록, `app.qss`의 `@이름` 치환(`theme::apply`)
- 아이콘: 창 아이콘(`setWindowIcon`, 16px은 픽셀 원본), Linux `setDesktopFileName`, 설치 시 Qt RPATH 유지
- **범위 밖**(로드맵에 남김): 세대 팝업과 `AppState`(A8), 화면 전환과 앱 막대(A9), 포커스 링(열린 질문 7), `--screenshot`과 `pokesix_app`(A3), 반응형(Phase F)

**기술 결정**
1. **토큰 이름은 핸드오프 그대로**(`tok::kRed`, `tok::kSizeIntroMark`) 쓴다. 열린 질문 5의 답이다. 새 핸드오프가 오면 파일째 다시 옮기고 diff로 비교할 수 있게 하기 위함이다. namespace만 `com::yamada::studio::tok`로 바꿨다
2. **글꼴(12 MB)은 실행 파일의 qrc에 넣는다.** 열린 질문 6의 답이다. `qt_add_big_resources`로 따로 된 오브젝트 파일에 넣어서, 거대한 생성 `.cpp` 없이 빌드가 빠르다. 배포할 때 글꼴 경로를 관리할 필요가 없다
3. **캡슐 마크는 핸드오프 SVG를 `QSvgRenderer`로 그린다.** `Qt6::Svg`를 새로 의존한다(`pokesix_ui` PRIVATE). A6의 원래 계획(QPainter로 직접 그리기)보다 원본과 정확히 같고 코드가 짧다. 직접 그려 보는 연습은 선택 과제로 남긴다
4. **QSS는 objectName으로 위젯을 고른다**(`QLabel#introSubtitle`). QSS의 타입 선택자는 namespace가 붙은 클래스 이름(`com::yamada::studio::…`)을 쓰기 불편하기 때문이다. `QLabel`은 전역에서 배경을 칠하지 않게 했다(무늬 위에 얹히므로)
5. **QSS로 안 되는 것은 `paintEvent`에서 그린다**: 창(`paintPanel`), 워드마크 글자 그림자, 세대 버튼, 메뉴 줄, 점선 구분선, 바탕 무늬
6. **글자 줄 높이 보정**: 브라우저의 `line-height: normal`과 Qt의 `QFontMetrics::height()`가 달라서(도현 22: 브라우저 26, Qt 32), 부제와 세대 라벨은 기준 이미지에서 잰 높이로 고정했다
7. **`enum class Page`**(`ui/shell/page.h`)로 인트로 → 본 화면 요청을 표현한다. 메뉴 순서와 같다
8. 사용자가 줄인 문구는 그대로 둔다([design/README.md](../../design/README.md) "의도한 차이")

## 결과

- 인트로 1440×900 캡처가 기준 이미지와 구조 · 좌표에서 일치한다. 남은 차이는 의도한 문구, 그리고 1–2px 수준의 글자 렌더링 차이다
- 로드맵 A2 · A4 · A5 · A6은 완료, A3 · A7은 일부 완료로 표시한다. 학습 루프상으로는 **구현된 코드를 읽고 설명할 수 있으면** 그 단계를 이해한 것으로 본다
- 새 의존성: Qt Svg 모듈(aqtinstall 기본 설치에 들어 있다)
