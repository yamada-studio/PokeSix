# 0015. 홈의 세대 선택을 카드 부채꼴로 바꾼다

- 상태: Accepted
- 날짜: 2026-10-02

## 맥락

[ADR 0008](0008-intro-screen-replaces-home.md)은 홈을 로고 · 세대 버튼 · 메뉴만 있는 인트로로
정했고, "다시 볼 조건: 인트로에 다른 정보(최근 스쿼드 등)를 넣자고 제안할 때"를 남겨 두었다.
사용자가 핸드오프 v1의 홈(SCR-01, 세대 카드 9장)을 다시 보고 "홈이 허하다"며 이렇게 요청했다:

- 세대 카드 9장을 **손에 쥔 패처럼 부채꼴로 펼치며** 시작하고, 클릭 · 슬라이드(끌기) 등
  이벤트별 애니메이션을 넣는다
- 카드 가운데에는 그 세대(지방)를 대표하는 인기 포켓몬 그림을 둔다 (세대별 마스코트는
  사용자가 지정)
- 최근 스쿼드 목록은 아직 넣지 않는다
- 부채꼴 바로 아래에 v1 홈의 바로 가기 버튼(스쿼드 · 도감 · 아이템)을 정렬한다

## 결정

- **세대 선택 = `CardFan`**(`ui/home/cardfan.*`). 카드 9장을 `paintEvent`에서 `QTransform`으로
  직접 그린다(자식 위젯 아님 — 회전 · 겹침 · z 순서를 다뤄야 해서). 클릭 판정은 역변환.
  - 펼침(보일 때마다 0 → 1, OutCubic) · 들림(hover · 선택, 카드마다 `QVariantAnimation`) ·
    흔들림(끌면 부채 전체가 돌고, 놓으면 OutBack으로 복귀)
  - AppState와 직접 잇는다: 누르면 `setGeneration`, `generationChanged`를 구독 — 앱 막대의
    세대 버튼과 양방향으로 맞는다. 키보드 ← → 로도 움직인다(HomePage가 전달)
- **카드 내용은 데이터로**: `resources/theme/homecards.json`(마스코트 · 윗띠 색 · 지방 이름
  ko/en/ja). 그림은 그 세대의 정면 스프라이트(`spritekeys::front`, 도감 상세와 같은 규칙)를
  실행 중에 사용자 캐시로 받는다 — 에셋은 커밋하지 않는다
- **세대 버튼(`GenerationButton`)은 홈에서 뺀다.** 부채꼴이 그 역할이다. 앱 막대의 버튼은 남는다
- **메뉴는 3줄 + 종료**: 스쿼드 · 도감 백과 · 아이템 백과 (단축키 1–3). **설정 줄은 뺀다** —
  설정은 본 화면 앱 막대 탭으로 간다(지금은 자리 표시 페이지라 잃는 것이 없다)
- 마크는 96(기존 136)으로 줄여 부채꼴의 세로 자리를 만든다
- 첫 실행(데이터 없음)에는 부채꼴을 숨기고 FirstRunPanel을 보인다(기존 compact 규칙에 편입)
- 기본 창 크기를 1440×900으로 키운다(부채꼴과, 도감 · 아이템의 세 칸 배치가 들어가는 폭)

## 결과

- v2 인트로의 기준 이미지(30–34)와 달라진다. 캡처 비교는 부채꼴 영역을 빼고 본다.
  v1 홈(SCR-01)의 대시보드(최근 스쿼드 · 모두 보기)는 여전히 채택하지 않았다 — 최근 스쿼드를
  넣자는 제안이 다시 오면 이 ADR을 잇는다
- 세대 카드의 마스코트 교체는 `homecards.json` 한 줄이다(컴파일 불필요)
- 다시 볼 조건: 세대가 10개를 넘어 부채꼴이 좁아질 때(카드 폭 · 벌어짐 각을 다시 잰다)
