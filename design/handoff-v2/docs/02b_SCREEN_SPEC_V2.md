### 동작

- 진입: 앱 시작 시 항상 인트로. 마지막으로 고른 세대를 보여 준다(`QSettings gen`).
- ↑↓: 선택 이동, 처음 · 끝에서 멈춤(순환 없음), 잠긴 줄은 건너뜀.
- Enter / 클릭: 해당 화면으로 즉시 전환(애니메이션 없음). 본 화면은 고른 메뉴의 탭이 활성.
- 1–4: 해당 메뉴 바로 실행.
- Esc: 선택을 종료 줄로. 종료 줄에서 Enter 또는 Esc 한 번 더 → 종료(확인 대화 상자 여부는 사용자 결정 대기).
- 세대 버튼: 클릭 · Space · Enter로 팝업, 팝업 안에서 ↑↓ · Enter · Esc(닫기).
- 본 화면 → 인트로: 앱 막대의 마크 버튼. 편집 중인 스쿼드는 자동 저장된 상태로 돌아온다.
