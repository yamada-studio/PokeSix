## SCR-04 · SixSquad 편집 ★ 핵심 화면

**목적** 6자리를 채우며 약점 · 저항 · 무효 분포와 공격 커버리지를 실시간으로 본다. **문제 지점이 먼저 눈에 들어와야 한다.**
**레이아웃(1440)** 상단 줄 44 → [슬롯 그리드 600 | 분석 창 가변].

### 상단 줄
이름(도현 28) · 이름 편집 버튼 · "4세대 규칙" 알약(노랑 바탕) · 슬롯 핍 6개(첫 타입 색, 빈 칸 흰) + "5 / 6" · (오른쪽) 자동 저장 상태(초록 ✓) · 복제 · 내보내기(파랑).

### 슬롯 그리드 (2열 × 3행, 간격 12)
- 채워진 슬롯: 디자인 시트 §5-6. 머리 이름 버튼 클릭 → 선택(노란 테 + ▶, 분석 히트맵 행도 노랑).
- 슬롯 메뉴(⋯): 포켓몬 바꾸기 · 비우기 · 위/아래로 · 도감에서 보기.
- 기술 칸 클릭 → 기술 선택 다이얼로그(해당 세대 습득 가능 기술만). 빈 칸 = 점선 "+ 기술 추가".
- 역할 메모: 한 줄 입력, 최대 40자.
- 빈 슬롯: "개체 추가"(빨강) → 포켓몬 선택 다이얼로그(도감 목록 재사용). 아래 제안 문구는 분석 결과에서 생성(예: "땅을 받아낼 수 있고 고스트 · 악 기술을 가진 포켓몬이면 문제 2건이 함께 풀려요").
- 드래그로 순서 변경(놓을 자리 = 파랑 점선).

### 분석 창 (파랑 머리 "실시간 분석" + 규칙 설명 + 빨강 "⚠ 문제 n")
1. **문제 목록** — 항상 맨 위. 행: 타입 XS 칩 · 제목(빨강 굵게) · 설명 · 태그(방어/공격). 행 hover → 관련 슬롯 빨강 테. 클릭 → 히트맵의 해당 열로 스크롤 · 깜빡(2회).
   - 방어 문제: 약점 수 ≥ 3 / 약점 ≥ 2 & 내성 · 무효 0 / 어떤 멤버든 ×4.
   - 공격 문제: 효과가 굉장한 기술이 하나도 없는 방어 타입.
2. **방어 상성 히트맵** — 행 = 슬롯(빈 슬롯 행 포함, 회색), 열 = 공격 타입 18. 요약 3행(약점 수 · 내성/무효 수 · 공격 커버). 문제 열 빨강 테. 범례 한 줄.
3. **물리 · 특수 분포** — 20칸 기준 누적 막대(물리 주황 · 특수 파랑 · 변화 회색 · 빈칸 사선), 수치 범례, "n세대~ 기술마다 판정" 알약, 그리고 **1–3세대 규칙(타입 기준)이었다면** 값 한 줄. 1–3세대 스쿼드에선 반대로 "4세대 이후 규칙이었다면"을 보여 준다.

**상태** 슬롯 0개: 분석 창 대신 빈 상태("첫 포켓몬을 추가하면 분석이 시작돼요"). 계산은 동기(6×18) — 로딩 없음.
**반응형** 1280 미만: 슬롯 3열 × 2행(메모 숨김, 타입은 머리의 XS 칩으로), 분석은 아래 **탭 [문제 n | 히트맵 | 물리 · 특수]**. 탭과 관계없이 문제 요약 한 줄(빨강 띠)은 항상 보인다. 960 미만 폭은 없음(최소 창).
