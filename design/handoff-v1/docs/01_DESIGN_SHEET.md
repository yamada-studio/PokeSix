## 5. 컴포넌트 규격

### 5-1. 앱 막대 `AppBar`
- 높이 60 (좁은 창 56) · 바탕 `red` · 아래 ink 3px.
- 왼쪽: 마크 32 (빨강 바탕용 변형: 빨강 칸 → 노랑, 외곽 흰 테) + "POKESIX" (SIX = `yellow.soft`). 1024 이하에선 워드마크 숨김.
- 탭: 비활성 높이 38, 바탕 `red.deep`, 흰 글자, 위 모서리 반경 8. **활성 탭은 높이 45로 막대 아래 선을 덮고** 바탕 `paper`, 글자 `red`, ink 3px 테두리(아래 없음) — 본문과 이어진 폴더 탭.
- 오른쪽: 세대 버튼(흰 바탕 · "GEN 4" 먹색 뱃지 + 지역명) · 전체 검색(폭 280, Ctrl K). 좁은 창에선 검색이 아이콘 버튼으로.

### 5-2. 창 `PanelFrame`
- 머리 색으로 역할 구분: 빨강 = 주 콘텐츠, 파랑 = 필터 · 분석 · 정보, 초록 = 분류 · 언어, 노랑 = 테마 · 보조, 먹색 = 설정 목록. 상세 창은 **선택한 포켓몬 첫 타입 색**.

### 5-3. 타입 칩 `TypeChip`
- 크기 MD(24) · SM(20, 표) · XS(20–22 정사각, 약칭). 결합형 듀얼(표): 한 테두리 안에 두 칸 + 2px ink 구분선.

### 5-4. 종족값 바 `StatBar`
- 라벨 44 · 수치 32(오른쪽 정렬) · 막대(높이 12, 반경 3, ink 1.5px 테두리, 트랙 `line.soft`). 채움 끝에 ink 1.5px 세로선.
- 채움 색은 **수치 구간**(타입 아님): ~59 `stat.low` · 60–89 `stat.mid` · 90–119 `stat.good` · 120+ `stat.high`. 최대 255 기준.
- 합계는 `red` 굵게. 표 안의 수치는 120+ `blue.deep` 굵게, 100–119 굵게, ~59 `red.deep`.

### 5-5. 히트맵 셀 `HeatmapWidget`
| 배율 | 바탕 | 글자 | 굵기 |
|---|---|---|---|
| ×4 | `#D8322B` | 흰 `4` | 700 |
| ×2 | `#F9CFC9` | `#8E1C16` `2` | 700 |
| ×1 | 흰 | (비움) | — |
| ×½ | `#D3E3F7` | `#1D4E8F` `½` | 700 |
| ×¼ | `#2C64B0` | 흰 `¼` | 700 |
| ×0 | `#2A2A33` | 흰 `0` | 700 |
| 세대 외 | 사선 무늬 `#EFEAE0`/흰 3px | `#9A96A0` `—` | 400 |

- 셀 34×26(1440) · 간격 2 · 셀 테두리 `#E4DDCF` 1px · 반경 3 · 글꼴 나눔고딕코딩 13.
- **문제 열**: 약점 수 ≥ 3, 또는 약점 수 ≥ 2이면서 내성 · 무효 수 0 → 열 전체를 `red` 3px 둥근 사각형(반경 5)으로 두른다.
- 선택 행: 라벨 칸 `yellow.tint`, ×1 셀 `#FFF9E0`.
- 요약 행: 약점 수(≥3 빨강 채움 · 2 `#F9CFC9`), 내성 · 무효 수(`blue.tint` + `blue.deep`), 공격 커버(✓ `green.tint`/`green` · ✕ 빨강 채움/흰).

### 5-6. 스쿼드 슬롯 `SquadSlotCard` / `EmptySlotCard`
- 채워짐: 창 규격 + 머리 40 (배경 = 첫 타입 색, 글자 = 그 타입의 글자색) · 번호(Silkscreen) · 스프라이트 자리 26 · 이름(도현 19) · 메뉴(⋯).
  본문: 타입 칩 → 역할 메모 입력(28) → 기술 2×2(칸 30, 타입 사각 10 + 이름 + 분류 칸 18) → 약점 XS 칩(×4는 빨강 채움 "얼×4").
- 비어 있음: `text.disabled` **2px 점선** · 사선 무늬 바탕 · 점선 육각 + "빈 슬롯" · 빨강 "개체 추가" 버튼 · 부족한 부분을 알려 주는 한 줄 제안.
- 선택: 바깥 노란 4px 테 + 머리 앞 ▶(노랑).
- 문제 관여(문제 행 hover 시): 테두리와 그림자가 `red`.
- 드래그 중 놓을 자리: 파랑 점선 + `blue.tint`.

### 5-7. 필터 칩 · 검색 · 버튼 · 토글 · 세그먼트
- 필터 칩: 높이 30, 반경 15. 기본 흰/ink 1.5px · 호버 `paper` · 선택 `yellow` 채움 + ink 2px + ✓ · 비활성 점선.
- 검색: 높이 36–38, 반경 6, ink 2px, 돋보기 아이콘, 오른쪽 단축키 표시(`line.strong` 테두리, 줄바꿈 금지). 포커스 시 테두리 `blue` + 바깥 `#CFE0F5` 3px.
- 버튼: 확정(빨강 채움) · 보조(흰) · 텍스트(파랑 글자) · 삭제(흰 + 빨강 테두리/글자).
- 토글 스위치: 50×28, 반경 14, ink 2px. ON 초록 · OFF `line`. 손잡이 20 흰 + ink 2px.
- 세그먼트: ink 2px 한 테두리, 칸 사이 ink 2px, 선택 칸 `yellow` 채움.

### 5-8. 빈 상태 · 로딩
- 빈 상태: 흰 육각 + 가운데 먹 육각(마크의 공동) · 제목(도현 21) · 이유 한 줄 · 다음 행동 버튼 2개.
- 로딩: 스켈레톤 행 — 불투명도 0.5↔1을 **4단 계단식**(`steps(4)`, 1.4s)으로. Qt에선 `QTimer` 350ms마다 단계 변경. 진행 막대는 10칸 세그먼트가 하나씩 초록으로 찬다.

## 6. 아이콘 · 마크

- `assets/icons/svg/pokesix-mark.svg` — 기본 마크. 칸: 오른쪽 위 빨강, 오른쪽 아래 파랑, 왼쪽 초록, 나머지 하양, 칸 사이 먹선, 가운데 먹 육각.
- 크기별 규칙: 칸 먹선 굵기 16px 10% · 32px 7% · 64px 5% · 128+ 3.4%. 가운데 육각은 64px 이상에서만.
- 16px은 벡터 축소 대신 **수작업 픽셀 원본**(`favicon/favicon-16.png`, `windows/pokesix-16-pixel.png`)을 쓴다.
- 플랫폼: macOS = 빨강 둥근 사각 플레이트(빨강 칸은 노랑으로), Windows = 플레이트 없는 육각 실루엣 + 흰 테, Linux = 흰 판 + 두꺼운 빨강 밑면.
- UI 아이콘(홈 · 도감 · 아이템 · 스쿼드 · 설정 · 검색 등)은 24 격자, 선 2.2, `currentColor`. 원본 SVG 경로는 `design/source/*.dc.html`의 인라인 `<svg>`에 있다 → `resources/icons/ui/*.svg`로 옮겨 쓴다.
