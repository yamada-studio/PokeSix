# 디자인 요청 0001 — 인트로(타이틀) 화면 · 앱 막대 탭 조정 · 마크 리디자인

> Claude Design에 그대로 붙여 넣는 요청서다. 기존 핸드오프(`design/handoff-v1/`)의 디자인 시스템을 **그대로 이어서** 쓴다.
> 결과물은 기존 핸드오프와 같은 구성으로 받아 `design/handoff-v2/`에 둔다. 기존 폴더는 수정하지 않는다.

---

## 0. 배경

PokeSix는 포켓몬 시리즈를 세대별로 정주행하는 성인 플레이어용 데스크톱 도구다(C++ / Qt 6 Widgets, 1440×900 기준).
지난 핸드오프의 홈 화면(세대 카드 9장 + 최근 스쿼드 + 바로 가기)을 **인트로(타이틀) 화면**으로 바꾸기로 했다.
옛 게임의 타이틀 화면처럼 로고 아래에 메뉴가 있고, 메뉴를 고르면 앱 막대가 있는 본 화면으로 들어간다.

**유지하는 것**: 색 토큰, 타이포그래피, 먹색 2px 외곽선, 블러 없는 오프셋 그림자, 컬러 머리의 각진 창,
노란 선택 칸 + ▶ 커서, 해요체 문구, 대비 4.5:1, 키보드 조작, 포켓몬 공식 에셋을 쓰지 않는다는 원칙.

## 1. 인트로 화면 (새 화면, SCR-01을 대체)

### 구성
- **앱 막대 없음.** 전체 화면을 인트로가 쓴다
- 가운데에 **로고**(마크 + "POKESIX" 워드마크)
- 로고 아래에 **현재 세대 버튼**: "GEN 4 신오 ▾" 형태. 누르면 1–9세대 목록(현재 세대에 ✓). 세대는 앱 전역 상태이며 모든 화면이 따른다
- 그 아래에 **메뉴**(세로 목록), 옛 게임 메뉴 문법(▶ 커서 + 노란 선택 칸):
  1. 도감 대백과
  2. 아이템 대백과
  3. SixSquad — 여섯 자리 파티 편성과 타입 분석
  4. 설정
  5. (선택) 종료 — 넣을지 여부는 디자인 판단에 맡김
- 메뉴 항목마다 짧은 설명 한 줄을 둘지, 이름만 둘지도 디자인 판단에 맡김(기존 바로 가기 카드의 설명 문구 재사용 가능)
- 구석에 앱 버전(예: `v0.1.0`), 데이터 출처 표기(PokéAPI) 정도의 작은 정보
- 바탕: `paper` 기반. 장식을 넣는다면 블러 · 그라데이션 · 연속 애니메이션 없이, 기존 사선 무늬 · 육각 모티프 수준으로

### 상태 (각각 그려 줄 것)
- 메뉴 항목: 기본 · 마우스 hover · 키보드 선택(▶ + 노란 칸) · 눌림 · 포커스 링(파랑 3px)
- 세대 버튼: 기본 · 열린 메뉴(1–9세대 목록)
- 첫 실행(데이터 없음): 메뉴 대신 또는 메뉴와 함께 "데이터 받기" 상태가 필요하면 제안

### 동작 (참고)
- ↑↓로 메뉴 이동, Enter로 선택, 마우스 hover가 선택을 따라감
- 메뉴 선택 → 해당 화면으로 전환(본 화면 = 앱 막대 + 페이지)
- 본 화면에서 앱 막대의 마크를 누르면 인트로로 돌아옴

### 크기
- 1440×900(기준), 1024×768, 960×640(최소 창)에서 잘림 없이

## 2. 앱 막대 조정 (SCR-00 수정)

- 인트로가 따로 있으므로 **"홈" 탭을 없애고 4개**(도감 · 아이템 · 스쿼드 · 설정)로 한다. 마크 + 워드마크가 인트로로 가는 버튼
- 세대 버튼과 전체 검색은 그대로
- 수정된 앱 막대가 들어간 화면 하나(예: 도감)만 다시 그려 주면 된다

## 3. 마크 · 앱 아이콘 리디자인

지금 마크("여섯 칸" 육각)는 **더 귀엽고, 더 둥글고, 손에 쥐는 공이나 캡슐 같은 느낌**이 나면 좋겠다.
포켓몬을 모으고 데리고 다니는 느낌이 나는 방향이다.

### 반드시 지킬 선 (중요)
- **포켓볼 도안을 쓰지 않는다.** 포켓볼은 상표이자 트레이드 드레스라서, 공개 저장소의 비공식 팬 도구가 쓰면 공식 제품으로 오인될 수 있다.
  다음 요소의 조합은 피한다:
  - 위 빨강 · 아래 하양으로 나뉜 원
  - 원을 가로지르는 검은 띠
  - 가운데의 원형 버튼
- 기존 마크가 가운데를 원이 아닌 육각으로 만든 것도 같은 이유였다. 이 원칙은 유지한다
- 포켓몬 캐릭터 · 공식 로고 · 공식 아트를 닮지 않게 한다

### 열어 둘 수 있는 방향 (예시, 디자인 판단에 맡김)
- 모서리를 많이 굴린 육각 · 말랑한 실루엣, 두꺼운 먹선의 스티커 느낌
- 알 · 캡슐 · 방울 같은 둥근 형태
- 여섯 자리(파티 6) 모티프: 여섯 개의 작은 구슬 · 칸 · 점
- 간단한 표정(눈 두 개 등)으로 캐릭터성 부여
- 주색 빨강 · 하양 + 보조 파랑 · 초록 · 노랑

### 받을 것
- 시안 2–3개를 나란히 비교한 보드 → 하나를 고른 뒤 확정안
- 확정안 SVG 원본 + 빨강 바탕용 변형(앱 막대) + 작은 크기용 단순화 변형
- 크기별 규칙(16 · 32 · 64 · 128+), 16px은 수작업 픽셀 원본
- 플랫폼 아이콘: macOS(`.icns` + iconset), Windows(`.ico` + png), Linux hicolor(16–1024 + scalable), 파비콘
- 워드마크 "POKESIX"와의 조합(가로형), 인트로 화면용 큰 로고

## 4. 결과물 형식

기존 핸드오프와 같은 구성으로 받는다.
- `images/screens/`: 인트로 1440 · 1024 · 960, 수정된 앱 막대 화면, 마크 비교 보드와 확정 보드
- `design/source/*.dc.html`: 수치의 정답(인라인 px)
- 토큰에 추가나 변경이 있으면 `tokens.json` · `Tokens.h` · `pokesix.qss` 갱신본과 변경 목록
- `assets/icons/`: 3절의 아이콘 전부
- `docs/`: 바뀐 부분만 적은 화면 정의서 · 디자인 시트 보충(SCR-01 인트로, SCR-00 수정, §6 마크)
